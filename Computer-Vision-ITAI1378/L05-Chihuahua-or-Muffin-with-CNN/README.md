# L05 - Chihuahua or Muffin with CNN

## Overview

In this lab, I implemented and evaluated a **Convolutional Neural Network (CNN)** for binary image classification using the Chihuahua vs. Muffin dataset. The project explored the complete CNN workflow, from image preprocessing and data augmentation to model training, evaluation, and performance analysis.

## Objectives

- Understand the architecture of Convolutional Neural Networks.
- Train a CNN for image classification.
- Compare CNN performance with a traditional neural network.
- Analyze model accuracy, misclassifications, and generalization.
- Explore real-world applications and ethical considerations of image classification.

## Topics Covered

- Convolutional Neural Networks (CNNs)
- Convolutional layers
- ReLU activation
- Max pooling
- Feature maps
- Data augmentation
- Image classification
- Model evaluation
- Deep learning for computer vision
