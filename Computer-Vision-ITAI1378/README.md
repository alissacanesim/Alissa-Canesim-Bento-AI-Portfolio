# Computer Vision and AI — ITAI 1378

This folder contains activities and projects completed for the Computer Vision and AI course at Houston City College.

## Course Overview

This course explores computer vision concepts and applications using Python and modern AI tools. Topics include image processing, object detection, image segmentation, model evaluation, pretrained vision models, and vision-language systems.

## Activities and Projects

The coursework in this folder includes practical activities involving:

- Image processing and analysis
- Object detection
- Image segmentation
- Model evaluation
- Pretrained vision models
- Vision Language Models
- Visual Question Answering
- OCR and document understanding
- AI hallucination testing and auditing

Additional activities and the final course project will be added as they are completed.
