# L06 - Object Detection Using Transfer Learning

## Overview

In this lab, I explored modern object detection and image segmentation techniques using the Ultralytics YOLO11 ecosystem. The notebook covers object detection, instance segmentation, foundation models, model evaluation metrics, and the relationship between these techniques and real-world Computer Vision applications.

## Objectives

- Perform object detection using YOLO11.
- Apply instance segmentation with YOLO11-seg.
- Compare specialist models with foundation models such as SAM 2.
- Understand evaluation metrics including IoU, Precision, Recall, and mAP.
- Explore confidence thresholds and their effect on detection results.
- Develop a midterm project proposal based on object detection.
