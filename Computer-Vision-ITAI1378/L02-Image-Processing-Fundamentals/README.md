# L02 - Image Processing Fundamentals

## Overview

This hands-on lab explored the fundamental concepts of digital image processing through practical implementations in Python. Using Google Colab, I analyzed how images are represented as pixel matrices and applied both traditional image processing techniques and modern computer vision concepts.

## Objectives

- Understand how computers represent digital images.
- Explore RGB channels and grayscale conversion.
- Apply brightness, contrast, and filtering operations.
- Perform histogram analysis and image enhancement.
- Implement geometric transformations.
- Connect traditional image processing techniques to modern AI applications.

## Topics Covered

- Digital image representation
- RGB color channels
- Grayscale conversion
- Brightness and contrast adjustment
- Convolution filters
- Edge detection
- Histogram equalization
- CLAHE
- Geometric transformations
- Traditional image processing and AI

## Technologies Used

- Python
- Google Colab
- OpenCV
- Pillow (PIL)
- NumPy
- Matplotlib

## Result

The lab successfully demonstrated core image-processing operations, including grayscale conversion, brightness and contrast adjustment, convolution filtering, histogram enhancement, and geometric transformations. Grayscale conversion reduced the image data size by 66.7% while preserving the main visual structure.
