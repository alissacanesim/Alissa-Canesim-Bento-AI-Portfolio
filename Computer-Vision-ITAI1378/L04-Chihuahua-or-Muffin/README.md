# L04 - Chihuahua or Muffin

## Overview

In this lab, I built and evaluated a neural network for binary image classification using the classic **Chihuahua vs. Muffin** dataset. The project introduced the fundamentals of deep learning for computer vision, demonstrating how neural networks automatically learn image features instead of relying on handcrafted feature extraction techniques.

## Objectives

- Train a neural network for image classification.
- Understand the end-to-end deep learning pipeline.
- Analyze model performance during training and validation.
- Explore the impact of hyperparameters on classification accuracy.
- Compare deep learning approaches with traditional computer vision methods.
