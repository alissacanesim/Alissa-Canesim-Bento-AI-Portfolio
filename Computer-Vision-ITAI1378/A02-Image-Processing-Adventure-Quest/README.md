# A02 - Image Processing Adventure Quest

## Overview

For this assignment, I completed the **Realm of Pixels and Color Models – Challenge 2** by creating an educational comic strip that introduces the fundamental concepts of pixels, RGB, and HSV color models through a Computer Vision scenario.

Instead of using a fantasy setting, I developed the story **"Alissa and the AI Vision Glasses"**, where the main character learns how computer vision systems interpret digital images.

## Objectives

- Explain how digital images are formed from pixels.
- Introduce RGB and HSV color models.
- Present image processing concepts in a creative and engaging format.
- Connect theoretical concepts to Computer Vision applications.

## Technologies Used

- Generative AI (comic illustrations)
- Graphic design tools
- Computer Vision concepts
- RGB and HSV color models

## Result

This project strengthened my understanding of how digital images are represented before they are processed by computer vision algorithms. Creating the comic also helped reinforce the practical differences between RGB and HSV color models while exploring a more engaging way to communicate technical concepts.
